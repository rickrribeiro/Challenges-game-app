## Key Interactions

1. **Setup → Game**: Configure players and difficulty, then start
2. **Game Flow**: Each player takes turns completing challenges
3. **Scoring**: Success adds points, failure subtracts points
4. **Game → Results**: Tap "End Game" at any time
5. **Results → Setup**: Tap "Play Again" to restart

- **Failure**: Red (#F44336)

- Clear visual feedback for current player
- Large, touch-friendly buttons
- Immediate score updates
- Round tracking
- Smooth transitions between screens
- Intuitive navigation
